# Code of Conduct

This project aims to be welcoming, respectful, and collaborative.

## Expected Behaviour

- Be respectful and constructive.
- Assume good intent.
- Focus feedback on the code and the problem being solved.

## Unacceptable Behaviour

- Harassment or personal attacks
- Discriminatory language
- Deliberate disruption of collaboration

## Enforcement

Project maintainers may update contribution expectations and moderation rules as
the repository evolves.
