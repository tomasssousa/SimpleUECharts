# Contributing

Thanks for your interest in contributing to `SimpleUECharts`.

## Current Stage

The repository is still in its setup phase. For now:

- keep changes aligned with `ROADMAP.md`;
- prefer small, focused pull requests;
- avoid introducing features that are outside the current roadmap.

## Development Notes

- The plugin is intended to remain lightweight.
- Initial scope is limited to bar and pie charts.
- UMG and Slate support should evolve together where possible.
